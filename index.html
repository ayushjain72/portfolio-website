My Projects

📌 Responsive Grocery Shop Website

The Responsive Grocery Shop Website is a frontend web development project designed to provide a clean, modern, and user-friendly shopping experience. The website includes a responsive navigation bar, hero section, product gallery, customer reviews, and a detailed footer with contact information.

This project was developed using HTML5 and CSS3 with a strong focus on semantic HTML, responsive web design, and modern CSS techniques. Flexbox and CSS Grid were used to create responsive layouts, while Media Queries ensured the website works smoothly on desktop, tablet, and mobile devices.

Interactive hover effects, transitions, and animations were added to improve the user experience. The project helped me strengthen my understanding of responsive layouts, Flexbox, CSS Grid, media queries, semantic HTML, and modern CSS styling.

Technologies Used: HTML5, CSS3, Flexbox, CSS Grid, Media Queries, Responsive Web Design, CSS Transitions, and CSS Transform.
